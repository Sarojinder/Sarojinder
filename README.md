## 🚀 Featured Projects

### 🤖 Embedded Robot Guidance System
- Developed a bare-metal embedded control system in HCS12 assembly
- Interfaced optical sensors through ADC channels for real-time feedback
- Implemented motor control using timers, GPIO, and an 8-state finite-state machine
- Debugged sensor, timing, and control behaviour through hardware testing

### 🎧 Real-Time Audio DSP System
- Built a real-time digital signal processing system on an Artix-7 FPGA
- Implemented FIR filtering, gain control, waveform generation, and sample buffering
- Developed custom I2S interfaces for an external stereo ADC/DAC
- Verified timing and functionality using testbenches, waveform analysis, and board-level debugging

### 🧠 32-bit CPU Design
- Designed a multi-cycle 32-bit processor with a custom datapath and control unit
- Integrated ALU, registers, program counter, memory, and instruction-control logic
- Developed 21 instruction-level verification tests
- Debugged control and timing behaviour using simulation waveforms

### 🖥️ Raspberry Pi Automation Platform
- Developed a modular Python system running on a Raspberry Pi 4
- Implemented persistent data storage, configuration management, structured logging, and automated workflows
- Added validation, retries, timeouts, testing, and error handling for reliable operation
- Used Linux, Git, SSH, and system-level debugging throughout development
