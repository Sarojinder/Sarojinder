# Hi 👋, I’m Sarojinder

I’m a Computer Engineering student at **Toronto Metropolitan University** and an aspiring digital hardware engineer focused on **RTL design, FPGA development, and design verification**.

## What to Expect

### RISC-V Processor on Basys 3

I’m building a **RISC-V processor in SystemVerilog**, starting with a pipelined core, UVM verification, and a demo on the Basys 3. From there, I plan to explore branch prediction, two-wide issue, out-of-order execution, and cache coherence.

### Digital FM Receiver on Basys 3

I’m starting with a **fixed-point FIR filter in SystemVerilog** and verifying it with UVM. From there, I’ll use the filter in a digital down-converter and add an FM demodulator to recover a test tone on the Basys 3.

I’ll share progress here as I build and test each milestone. Keep an eye out!
